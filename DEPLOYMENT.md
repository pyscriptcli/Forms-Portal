## ⚡ Step 2: Import into Vercel

1. Log into your [Vercel Dashboard](https://vercel.com).
2. Click **"Add New..."** ➔ **"Project"**.
3. Under **"Import Git Repository"**, find and select **`Forms-Portal`**.
4. **Framework Preset**: Next.js (automatically detected).
5. **Root Directory**: `./` (leave default).

---

## 🌐 Step 4: Click Deploy!

Click **"Deploy"**. Vercel will:
1. Run `npm install`
2. Run `npm run build`
3. Deploy to a global edge network in ~60 seconds.

## 🔗 Step 5: Custom Domain Setup (Optional)

To use an official PRIME Philippines domain (e.g. `forms.primephilippines.com`):
1. In Vercel, go to **Settings** ➔ **Domains**.
2. Enter `forms.primephilippines.com`.
3. Add the CNAME record generated by Vercel in your DNS manager (Cloudflare / GoDaddy / Route 53).
4. Update `NEXT_PUBLIC_APP_URL` in Vercel Environment Variables to `https://forms.primephilippines.com`.
